# j01 - Mi servidor de base de datos

## Paso 1. Predicciones

**1. ¿Se conservan los datos después de stop y start?**

Sí, porque el contenedor se detiene, pero no se elimina y los datos permanecen guardados.

**2. ¿Se conservan los datos después de down -v?**

No, porque se eliminan los volúmenes de Docker Compose, donde se almacenan los datos de MySQL.

**3. ¿Por qué utilizamos 127.0.0.1?**

Porque permite acceder al servidor desde nuestro propio ordenador, sin exponer directamente el puerto a otros equipos de la red.
