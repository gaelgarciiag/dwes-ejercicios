
# ej02 - CRUD en SQL

## Pregunta 1. Error 1451

Los datos los protegió la propia base de datos mediante una clave foránea (FOREIGN KEY).

Esta restricción impide borrar un producto que está relacionado con una línea de pedido, manteniendo la integridad referencial.

## Pregunta 2. Transacciones

Sin START TRANSACTION, si trabajamos con autocommit activado, el UPDATE se habría guardado automáticamente y ROLLBACK no habría recuperado los precios anteriores.

START TRANSACTION permite realizar cambios y deshacerlos con ROLLBACK antes de confirmarlos.
